نسخة احتياطية

احفظ النص أو الملف في مكان آمن (iCloud Drive أو الملاحظات). للاستعادة الصق النص هنا أو اختر الملف ثم اضغط «استعادة».

ربط حساب جوجل

تسجيل الدخول بجوجل عادي (اسم وبريد فقط، بدون Drive). تحتاج إعدادًا مجانيًا مرة واحدة عبر Firebase:

  1. أنشئ مشروعًا في console.firebase.google.com.
  2. Authentication ← Sign-in method ← فعّل Google، وانسخ «Web client ID».
  3. في Google Cloud ← Credentials ← افتح هذا الـ Web client وأضف رابط موقعك (https) في Authorized JavaScript origins، وأضف نطاقك في Authentication ← Settings ← Authorized domains.
  4. Firestore Database ← Create، ثم Rules والصق القاعدة بالأسفل ← Publish.
  5. Project settings ← انسخ Web API Key و Project ID.
rules_version = '2';
service cloud.firestore {
  match /databases/{d}/documents {
    match /adhkar/{uid} {
      allow read, write: if request.auth != null
                         && request.auth.uid == uid;
    }
  }
}
